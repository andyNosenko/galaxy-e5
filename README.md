## Структура проекта

```
galaxy_e5/
├── apps_to_install/     # Директория для APK файлов
├── backup/             # Директория для резервных копий
├── logs/               # Директория для логов
└── scripts/            # Скрипты для работы с ADB
    ├── adb_utils.sh    # Общие функции для работы с ADB (Linux)
    ├── adb_utils.bat   # Общие функции для работы с ADB (Windows)
    ├── adb_test.sh     # Тестирование ADB соединения (Linux)
    ├── adb_test.bat    # Тестирование ADB соединения (Windows)
    ├── backupzip.sh    # Создание резервной копии (Linux)
    ├── backupzip.bat   # Создание резервной копии (Windows)
    ├── restorezip.sh   # Восстановление из копии (Linux)
    ├── restorezip.bat  # Восстановление из копии (Windows)
    ├── start.sh        # Основной скрипт (Linux)
    ├── start.bat       # Основной скрипт (Windows)
    ├── config.sh       # Конфигурация (Linux)
    ├── config.bat      # Конфигурация (Windows)
    └── logger.sh       # Функции логирования
```

## Требования

- Android Debug Bridge (ADB) установлен и доступен в системе
- Не менее 20-30 ГБ свободного места для резервных копий
- Подключенное Android устройство с включенным режимом разработчика и USB-отладкой

## Использование

### Linux
```bash
cd scripts
chmod +x *.sh
./start.sh
```

### Windows
```batch
cd scripts
start.bat
```

## Функциональность

1. **Проверка ADB-соединения**
   - Проверка наличия ADB в системе
   - Проверка подключения устройства
   - Проверка состояния устройства

2. **Управление приложениями**
   - Установка APK из директории apps_to_install
   - Удаление приложений
   - Просмотр списка установленных приложений

3. **Резервное копирование**
   - Создание полной резервной копии
   - Восстановление из резервной копии
   - Управление резервными копиями

4. **Логирование**
   - Автоматическая ротация логов
   - Разные уровни логирования (INFO, ERROR, DEBUG)
   - Сохранение логов в директории logs

## Важные замечания

- Перед началом работы убедитесь, что устройство подключено и распознается системой
- Рекомендуется иметь не менее 20-30 ГБ свободного места для резервных копий
- Не пытайтесь вносить изменения или производить перепрошивку устройства без создания резервной копии
- Все операции логируются в директории logs для отслеживания процесса и диагностики проблем
